# オセロゲーム（仮称: NEON OTHELLO）要件定義書

**バージョン**: v0.9（ドラフト・承認待ち）
**作成日**: 2026-09-24（JST）
**作成者**: ルビー
**ステータス**: kokuten さんへの質問（§8）への回答を得て v1.0 確定とする

---

## 1. 背景と目的

- スマートフォン／タブレット向けブラウザオセロ（PWA）を新規開発する。
- 既存の NEON TETRIS v2（GitHub Pages + Supabase + Google OAuth）のインフラ・ノウハウを再利用し、短期間で高品質に立ち上げる。
- よくあるオセロ機能（AI対戦・オンライン対戦・ランキング・履歴）を土台に、**石のカスタマイズ（色／Googleアイコン）** と **レベルシステム＋賑やかしレベルアップ演出** をオリジナリティとして差別化する。

## 2. ユーザーと利用環境

| 項目 | 内容 |
|---|---|
| ターゲット端末 | iOS / Android のスマートフォン、タブレット |
| 実機 | Galaxy Fold 8（展開時 4:3 横長 / 折り畳み時縦長）、iPad、Android |
| 利用場面 | 外出先での短いプレイが多い（QRコード配布・即開ける URL が重要） |
| 画面回転 | 縦長⇔横長を双方向サポート。回転しても盤面・進行状態を失わない |
| 入力 | タッチ主体（盤面タップ＝着手）。マウスホバー用ヒントも併設 |

## 3. 機能要件

### 3.1 認証（Must）
- **F-101** Google OAuth によるログイン（Supabase Auth 経由、既存テトリスと同じ方式）。
- **F-102** セッション自動復元（アプリ起動時に再ログイン不要）。
- **F-103** 表示名は初期値＝Googleアカウントの表示名。設定画面から変更可（20字以内）。
- **F-104** Googleアイコン（avatar URL）を取得し、プロフィール・対戦相手一覧・ランキング・石のテクスチャに利用可。
- **F-105** 未ログインでも AI 対戦のみプレイ可能（ランキング投稿・オンライン対戦はログイン必須）。

### 3.2 ゲーム本体（Must）
- **F-201** 標準オセロルール（8×8、黒先手、初期4石配置、挟み返し、打てない升はパス、パス2回／64石で終局）。
- **F-202** AI対戦：難易度を選択可（初級〜最強の複数レベル。詳細は設計書 §5）。
- **F-203** オンライン対戦：待機中の対戦相手一覧から相手を選んで対戦（§3.4）。
- **F-204** 同一端末2人対戦（ローカルパスアンドプレイ）。※要確認（Q-3）
- **F-205** 合法手のリアルタイム表示（候補マーカー）、最新着手位置のマーキング。
- **F-206** 返される石のプレビュー（着手前にホバー/長押しでどこが返るか示す）。
- **F-207** 石が返るアニメーション（方向が一目で分かる回転／めくりアニメ）。※ユーザー設計要件（回転方向が視覚的に明確であることは設計要件）
- **F-208** 引数カウンタ（自分の石/相手の石）、手番表示、パス発生時の明示と確認。
- **F-209** 終局判定・勝敗表示（同数＝引き分け）。
- **F-210** 対局中のタイムアウト処理（一手制限時間）。※要確認（Q-5）

### 3.3 対戦結果の保存（Must）
- **F-301** 全対局（AI/オンライン/ローカル）を履歴としてクラウド保存（オンライン・ログイン時）。
- **F-302** 履歴画面：日時・相手・戦型（手数）・結果・石数差を表示。
- **F-303** 戦績サマリー：総対局数・勝率・連勝記録（現連勝/最長連勝）。
- **F-304** 対局中断時の途中保存と再開（オンライン対戦の再接続含む）。

### 3.4 オンライン対戦・マッチング（Must）
- **F-401** 「対戦相手を探す」で待機リスト画面へ。待機中のプレイヤー（名前・レベル・アイコン・戦績）を一覧表示。
- **F-402** 一覧から相手を選んで「対戦を申し込む」。相手側に応答ダイアログ（受諾/拒否/自動タイムアウト）。
- **F-403** 自分が待機側の場合も一覧へ載る。待機解除・自分だけを表示フィルタ（レベル帯で絞る）※要確認（Q-2）
- **F-404** 対局中の離脱・通信断対処：再接続で盤面復元、一定時間復帰なき場合は不戦敗。
- **F-405** 同IDへの同時申込・自分自身との対戦防止。

### 3.5 レベルシステム（Must）
- **F-501** 経験値（XP）によるユーザレベル。対戦結果・手数から自動加算（設計書 §6 に計算式）。
- **F-502** レベルはゲーム画面（自分と相手のHUD）、対戦相手一覧、ランキング、履歴に表示。バッジ＋数値。
- **F-503** レベル帯の称号（例: 見習い→初段→有段→名人→マスター）をランキングとプロフィールに表示。
- **F-504** **レベルアップ演出（賑やかし）**：レベルアップ瞬間に全画面コンフェッティ＋称号獲得トースト＋効果音＋（称号変更時は一段と豪華な演出）。
- **F-505** 勝敗数ではなく XP ベース（遊ぶほど育つ）＋勝敗ボーナス。※ランキングの順位軸は要確認（Q-4）

### 3.6 ランキング（Must）
- **F-601** 全世界ランキング：レベル（XP）順／勝利数順／勝率順をタブで切替。
- **F-602** 上位N位＋自分の順位を必ず表示（下位でも「あなたの順位: ○位」）。
- **F-603** 期間ランキング（週間・月間）を検討。※要確認（Q-4）
- **F-604** 未ログインでも閲覧のみ可能。

### 3.7 石・盤面のカスタマイズ（Must・オリジナリティ中核）
- **F-701** 先手／後手の石色を自由設定：プリセットパレット（定番の黒白、ネオン、パステル…）＋カラーピッカー自由選択。
- **F-702** 石テクスチャに Google アイコンを適用可（自分の石＝自分のアイコンなど）。
- **F-703** オンライン対戦時のアイコン石の扱い：両者のアイコンを石に使う（相手が拒否するオプションも可）。※要確認（Q-1）
- **F-704** 盤面背景・盤の色のカスタマイズ。※優先度_low（あると嬉しい）
- **F-705** カスタマイズはプロフィールに紐づけてクラウド保存（別端末でも復元）。

### 3.8 音・演出（Must）
- **F-801** 着手音・返す音（返す石の数に応じた連続音）、勝利/敗北/レベルアップジングル。ミュート永続設定。
- **F-802** BGM は任意（軽くループする環境音レベル）。※要確認

### 3.9 公開形態（Must）
- **F-901** GitHub Pages 静的デプロイ + PWA（オフライン起動対応・ホーム画面追加可）。
- **F-902** 画面タイトル直下にアプリバージョン表示（semver、既存規約）。
- **F-903** 公開 URL の QR コード生成・配布。

## 4. 非機能要件

| ID | 要件 |
|---|---|
| NF-01 | 初回表示 ≤3s（4G相当）、ローディング中に盤面スケルトン |
| NF-02 | オンライン対戦の一手同期遅延 ≤ 500ms 体感（Realtime Broadcast） |
| NF-03 | AI思考はUIを止めない（Wasm/ワーカー。最長でも進捗表示） |
| NF-04 | RLS によるデータ保護（他人名義の投稿・改竄防止は更新不可ポリシー） |
| NF-05 | 344×882（縦）〜 1000×750（Fold8展開横長）まで連続対応 |
| NF-06 | 回転・サイズ変更時に盤面を再レイアウトし、スクロール位置と対局状態を維持 |
| NF-07 | 低性能端末でも60fps目標のアニメ（めくりはCSS/GPU合成、Pixiは任意） |
| NF-08 | Supabase Free枠内で運用（Realtime同時接続200／月200万メッセージ） |

## 5. 調査サマリー（世の中の情報・2026-09-24）

- **AI水準**: 上位アプリは1手先〜8手先読み、最上位は世界最強オープンソースAI「Egaroucid」（20手以上）相当。参考: リバーシWeb（yuki-lab）。→ 本アプリは Negamax＋Alpha-Beta＋Bitboard＋評価関数（角・辺優先／打ち得・返し数）で中〜上級をカバー、最強帯は将来 Egaroucid 互換エンジン移植を検討。
- **人気アプリの共通機能**（みんなのオセロ/オセロクエスト/リバーシZERO等）: 難易度多段階、オンライン対戦（ランキング連動）、連勝記録、一手タイマー、ヒント。→ 全て本要件に織り込み済み。
- **UXの定番**: 合法手マーカー、返す石プレビュー、盤面を最大サイズで中央確保、HUDは縦長時は上下・横長時は左右パネル。スマホのオセロで最も不満が出るのは「盤面が小さい／指が盤を隠す」→ 盤面は `min(100vw, 62vh)` 等で自動最大化する。
- **オンライン同期方式**: Supabase Realtime（Broadcast＋Presence）でターン制対戦をサーバーレス実現した実績多数（Emojitsu 等）。ターン制オセロには十分（WebSocket遅延 ~50-100ms）。
- **デザイン**: 既存 NEON TETRIS 系のネオンダークUI資産（Orbitron/GSAP/howler/PWA設定）を流用すれば開発効率が最も高い。ただしオセロ専用の和モダン／木製風への転換も選択肢（Q-6）。

## 6. スコープ外（Round 1）

- ネイティブアプリストア配信（ブラウザ/PWAのみ）
- LINE認証（テトリス同様 Round 2）
- 段位認定・大会・ルームコード対戦（招待リンク対戦は Q-7 で判断）
- 対戦チャット・絵文字リアクション（Round 2 候補）
- 棋譜の再生・エクスポート（Round 2 候補）
- 多言語（日本語のみで開始）

## 7. 成功指標（初回公開後1ヶ月）

- AI対戦完走率 > 70%、オンライン対戦成立率 > 80%（申し込んだ対局が開始できる割合）
- レベルアップ演出の実装（スクショで賑やかしが確認できること）
- Fold8 実機で縦/横どちらでも親指だけで最後までプレイできること

| # | 質問 | ルビー推奨 |
|---|---|---|
